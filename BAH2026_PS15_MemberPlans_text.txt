Data Handoff Contract (lock these column
names on Day 1 — do not improvise later)
A delivers → data/processed/combined_lightcurve.csv :
| Column | Type | Notes |
|---|---|---|
| timestamp  | ISO8601 UTC | common cadence, resampled if needed |
| soft_xray_flux  | float | SoLEXS / GOES soft channel |
| hard_xray_flux  | float | HEL1OS hard channel |
| soft_bg_subtracted  | float | after background removal |
| hard_bg_subtracted  | float | after background removal |
| source  | string | aditya  or goes  |
B delivers → data/processed/features.csv  (built on top of A's file,
same timestamp  key):
| Column | Type | Notes |
|---|---|---|
| timestamp  | ISO8601 UTC | join key |
| hard_rate_of_rise  | float | |
| hardness_ratio  | float | hard/soft flux |
| soft_bg_trend  | float | |
| recent_flare_count  | int | active-region productivity proxy |
| label_30min  / label_60min  / label_120min  | bool | ground-truth
flare-within-window labels |
C delivers → outputs/catalogue/master_catalogue.csv :
| Column | Type | Notes |
|---|---|---|
| start_time , peak_time , end_time  | ISO8601 UTC | |
| flare_class  | string | e.g. M5.2  |
| confidence  | string | hard-confirmed  / soft-only  |
Rule: if anyone needs to change a column name or format, they say so
in the daily stand-up before changing it — not silently.
